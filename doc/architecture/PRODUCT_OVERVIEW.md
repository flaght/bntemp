# Bomber 量化交易平台功能介绍

更新日期：2026-11-02，Asia/Shanghai。按当前framework源码整理，定位为整体功能与设计介绍；详细模块及适配边界见[框架源码总览](../../bomber/framework/README.md)。本次为静态文档更新，未重新执行测试或连接交易端。

Bomber以**积木化搭建、配置化装配和标准接口解耦**为核心，在Nautilus数据模型、指标及回测内核之上，把行情、资料、特征、策略、仓位、组合、风控、执行和运行生命周期组织为可复用组件。同一策略逻辑可用于回测与Live，行情来源和下单端独立选择，多策略可采用同进程或同机独立进程布局；新增业务优先复用组件、调整配置和绑定，需要新协议时补充适配器，减少重复开发及对策略核心的侵入。

## 1. 积木化搭建与灵活适配

- 按业务组合数据Provider、行情Feed、策略、Runtime、执行Backend及市场规则Profile。
- 分别声明信号数据绑定与目标交易路由，支持行情标的和交易标的不同。
- 复用已有组件时切换配置／装配；新增数据源、交易端或特征来源通过对应接口扩展。
- 市场规则、手续费、账户观测和运行政策与策略算法分离。
- 具体组合仍需满足标的、字段、时间、平台与执行能力契约；不是任意组件无条件互换。

## 2. 多来源行情与统一输入

- 接入本地CSV／Feather回放、CTP、DolphinDB及Binance行情。
- 统一处理TradeTick、QuoteTick、Bar及CustomBar，支持分钟聚合、多合约同步和行情时效检查。
- 通过显式映射保留模型需要的原始OHLCV、成交额、持仓量和时间标签。
- 按声明处理已完成分钟与分钟状态流，校验累计量／本周期量、时区和完成边界。
- 匹配不同策略和频率的输入需求，具体源与入口能力分别核验。

## 3. 基础资料、交易会话与研究数据

- 管理期货／期权条款、生命周期、乘数、跳价、期权关系及合约角色。
- 支持主力／次主力／远期映射、累计因子及复权研究价格，真实订单保持可交易合约价格口径。
- 统一交易日历、时段、夜盘归属、跨午夜及特殊日期例外。
- 按业务时间和已知可见时间查询参考数据，记录来源、版本与资料覆盖。

## 4. 同策略回测与Live

- 策略使用同一StrategyTemplate和目标仓位接口，复用指标、业务算法及公共装配。
- 提供信号回放、Nautilus正式回测、在线Recording和参考价Model等运行方式。
- Runtime管理时间与生命周期，Backend管理模拟或柜台执行，二者分别选择。
- 正式回测支持原生撮合时序及next_market模式；后者按订单自身合约的后续有效行情推进，可配置延迟Bar数。
- 不把参考价模型成交视为柜台成交，也不把简单信号回放等同正式回测。

## 5. 历史预热与实时接续

- 通过HistoryService读取DolphinDB或已声明的历史来源，初始化指标和滚动窗口。
- 复用交易分钟窗口、多腿同步覆盖、实时缓冲、合并去重及缺口检查。
- 保留不同策略的原始价差、复权价格或模型字段口径。
- 历史只用于状态预热，后续新鲜实时输入才触发交易。
- EMA、跨期及横截面已有部分CFFEX场景的实际历史接续记录。

## 6. 自定义特征与DataHub

- 配置接入指数、现货报价、外部指标及已计算因子，统一字段、Schema和计算版本。
- 支持标准文件导入导出、DolphinDB／MongoDB Provider及原表映射。
- 提供EXACT／WINDOW／ASOF对齐、修订选择、可见时间以及迟到／缺失处理。
- 08期权回测已接与默认DFS Live共用的指数特征契约，使用模拟可见时钟，复用原策略帧接口。
- 新特征可复用已有Provider及映射；新的特征计算仍需相应算法，实际业务组合另行验收。

## 7. 目标仓位、组合与独立策略账本

- 策略提交完整或局部目标组合，公共层完成目标版本、合约路由、组合汇总及差额订单规划。
- 跟踪已成交份额、在途数量和订单回报，分别管理策略自有仓位、系统账本与外部持仓基线。
- 支持显式的账户strict／observe／off与fills／model仓位政策，按合法组合使用。
- 策略仓位不被账户净仓覆盖；模型份额与真实归属、内部划转与柜台成交分别审计。

## 8. 同账户多策略与两种进程布局

- 支持同进程共享宿主，以及同机Unix IPC下的独立策略进程。
- 同一物理账户由唯一执行服务管理连接、订单编号、风险和状态。
- netted模式汇总目标并按政策抵消；independent模式保留各策略真实订单及归属。
- 支持同合约多个策略的同向／反向份额、回报事件确认和重连补交。
- 已有局部真实多策略成交及对账证据，完整停止／恢复组合持续按固定条件验收。

## 9. CTP、Binance与LXGBN执行接入

- CTP提供原生连接、认证、结算确认、资金／持仓／委托查询、报撤单及成交回报。
- 通过Planner与Ledger管理期货开平和今昨仓，处理拒单、撤单失败及断线保护。
- Binance已有TradingNode、权威账户／活动单读取和DEMO执行装配能力，完整实际链路范围另验。
- LXGBN采用Windows宿主内嵌Python调用Bomber SDK，复用现有策略、OMS、风控、归属和持久化。
- LXGBN已有SDK、原生接线组件及Windows安装／同进程导入验证，实际宿主交易仍待验；不以旧HTTP桥方案描述当前架构。

## 10. 手续费、市场规则与期权结算

- 期货费用支持元／手和成交金额比例、全局／品种／合约覆盖系数，以及逐笔标准费用和实际扣费审计。
- Profile组合费用、保证金、撮合及延迟模型，基础NETTING与双向／今昨账本按适用范围选择。
- 提供显式期权到期现金结算组件，根据最后交易日和真实最终结算资料处理实际残仓。
- 结算可用控制时钟推进并回写原生账户和归属；该能力不等于所有期权的实物交割和行权机制。

## 11. 公共生命周期、常驻运行与恢复

- 统一Live准备、就绪检查、历史准备、检查点提交、授权及停止收尾。
- 管理交易窗口、休市等待、当日报单额度与停止信号。
- 采用原子检查点、代次校验、对象绑定和目标／组合一致性核验，保留订单关联、成交去重及业务状态组件。
- 针对查询超时、迟到行情、恢复身份和停止过程补充保护与诊断。
- 01／10已接公共高层常驻入口；08已有公共常驻链路，高层统一仍待办；03／04未因此自动具备常驻模式。

## 12. 策略与应用示例

| 示例 | 功能 |
| --- | --- |
| 主力EMA、产业链联动 | 趋势／联动信号，支持合约角色和执行路由 |
| 跨期、横截面、角色穿越、三品种相对价值 | 多腿同步、价差／收益排序及组合目标 |
| 外部目标计划 | 按时钟或市场事件将外部完整目标变为订单 |
| 期权Vega与Delta | Vega预算卖方、期货Delta对冲，以及Delta选约双腿买入回测 |
| HybridTransformer | 外部模型推理、按品种信号配置和有期限的分批持仓 |
| 日目标CTA与期货／期权目标持仓回测 | 复用公共行情、规划、风控、撮合和结算组件 |

这些应用展示框架装配方式，业务算法保留在[demos](../../demos)，不进入framework。各示例是否具备Live、常驻或指定执行端，以自身入口为准。
