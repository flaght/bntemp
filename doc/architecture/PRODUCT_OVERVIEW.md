# Bomber 量化交易平台功能介绍

功能状态依据截至 2026 年 10 月 16 日的架构台账与验收记录整理。

## 1. 统一策略开发

- 同一套策略逻辑用于历史回测和在线运行。
- 行情来源、执行组件与策略算法分别配置。
- 支持行情标的与交易标的不同，按逻辑角色绑定实际合约。
- 可复用 EMA、ATR 等 Bomber／Nautilus 指标组件。

## 2. 多来源行情接入

- 接入 CTP、DolphinDB、Binance 行情及 CSV、Feather 历史文件。
- 统一处理报价 Tick、成交 Tick 和 Bar 数据。
- 支持分钟线聚合、多合约同步、分钟帧对齐与行情时效检查。
- 行情来源和交易执行端独立选择；具体组合按标的与来源能力配置。

## 3. 历史回测与在线仿真

- 历史信号回放：检查策略信号、目标仓位和执行路由。
- 正式历史回测：使用 Nautilus 模拟时钟、订单生命周期与撮合能力。
- 在线目标记录：接收实时行情并记录策略目标。
- 在线模型成交：按参考价生成模型订单与成交，维护独立模型仓位。
- 支持初始资金、手续费和保证金等参数配置；模型成交与柜台成交分别记录。

## 4. 历史预热与实时接续

- 从 DolphinDB 加载历史行情，初始化指标和滚动窗口。
- 支持历史窗口、频率、实际合约及多腿输入配置。
- 提供加载期间的实时行情缓冲、时间对齐、合并去重和缺口检查。
- 历史预热只更新指标状态，完成后由新的实时输入触发交易决策。
- EMA、跨期和横截面策略已有部分中金所场景的实际历史接续记录。

## 5. 策略示例库

| 策略 | 功能 |
| --- | --- |
| 主力合约 EMA | 根据 EMA 信号生成多空目标，支持主力角色与复权研究价格 |
| 产业链联动 | 使用多个产业链品种生成信号，支持信号角色与执行角色分别配置 |
| 单品种跨期价差 | 使用同品种不同期限合约构建价差，按滚动统计信号调整双腿仓位 |
| 多品种横截面动量 | 对同步收益率排名，按多空分组与名义金额预算配置仓位 |
| 三角色复权价穿越 | 比较主力、次主力和远期角色的复权研究价格，生成交易信号 |
| 三品种相对价值 | 使用一个锚定品种与两个对冲品种构建相对价值组合 |
| 外部目标计划 | 读取外部完整目标仓位计划，按时钟触发组合调整 |
| 期权 Vega 卖方 | 按固定 Vega 预算卖出虚值认购期权，依据实际归属仓位计算 Delta 并生成同月期货对冲目标 |
| 期权 Delta 双腿买入 | 按期限和绝对 Delta 选择虚值认购、认沽期权，提供双腿买入与换仓回测 |

各策略的在线入口和验收范围不同，具体以对应示例说明为准。

## 6. 目标仓位与组合管理

- 策略提交逻辑目标仓位，平台负责实际合约路由与订单生成。
- 支持完整目标替换、局部更新、目标版本及有效期管理。
- 按账户和合约汇总策略贡献，计算目标与当前仓位之间的差额。
- 跟踪已成交仓位、在途数量和执行回报。

## 7. 同账户多策略运行

- 支持同进程共享宿主和同机独立策略进程两种运行布局。
- 多策略共用账户执行服务，统一管理连接、订单编号与账户状态。
- 提供目标净额合并和策略独立订单两种执行模式。
- 按策略记录目标版本、订单份额及成交归属。
- 已取得部分多策略实际成交与归属记录，完整三策略停止和恢复仍在验收。

## 8. 策略独立仓位管理

- 分别保存策略归属仓位、物理账户仓位和外部持仓基线。
- 根据已归属成交更新策略账本。
- 支持显式持仓初始化、检查点保存和已有归属恢复。
- 保存订单关联与成交去重信息，支持按既有政策核对恢复条件。
- 已有局部同交易日恢复证据；完整跨日与异常断点恢复仍在完善。

## 9. CTP 在线交易

- 提供原生连接、认证、登录与结算确认。
- 查询资金、持仓及活动委托，处理订单和成交回报。
- 支持报单、撤单、期货开平仓及今昨仓规划。
- 将拒单、撤单失败和断线等异常纳入执行保护。
- 已有 SimNow 期货、期权及部分双腿交易的柜台成交记录。

## 10. 自定义特征接入

- 接入指数、外部指标等非交易数据。
- 通过声明配置字段结构、数据版本、来源和对齐方式。
- 提供可见时间、迟到及缺失数据处理能力。
- 期权策略已使用在线指数特征；公共文件回放能力已有，08 正式回测的同特征链路仍待补齐。

## 11. 风控与运行保护

- 提供数量、仓位、名义金额和资金等执行条件检查。
- 检查行情时效、依赖合约、参考资料及交易日一致性。
- 支持异常禁单、紧急停止、成交去重和状态持久化。
- 恢复时核对会话身份、订单关联及仓位归属。
- 按交易日历和交易时段编排运行；部分持续入口支持休市等待与下一窗口恢复。

## 12. 报表与交易审计

- 输出信号、目标、订单、成交、持仓与运行摘要。
- 提供期权候选、选约结果、决策及拒绝原因记录。
- 记录历史预热覆盖、输入缺口和实时接续情况。
- 支持 CSV、JSON 和可选绩效图，便于分析结果与追踪交易过程。

## 当前完善中的功能

- 完整三策略在两种进程布局下的运行、停止与恢复验收。
- Binance／LXGBN 正式执行配置接入及实际场景验收。
- 08 期权正式回测与在线自定义特征链路统一。
- 冻结品种组合的历史数据覆盖与完整预热验收。
- 通用多腿协调、异常补偿及更完整的跨日恢复。
- 更完整的交易所仿真规则与真实多账户执行验收。
