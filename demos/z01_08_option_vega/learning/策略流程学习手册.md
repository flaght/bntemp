# MO认购卖出策略流程学习手册

更新日期：2026年11月19日。适合期权入门者，按当前仓库实现理解策略，不展开新旧版本绩效比较。日内时点均为上海时间。

这套策略在指定时点卖出认购，用Gamma决定各Delta档的相对手数，用共享Vega预算决定新增规模，再以同月IM期货管理实际期权持仓的Delta敞口。旧仓逐日保留，直到满足退出、主动清仓或到期结算条件。最终盈亏要合并期权和期货两条腿。

本手册配套[习题答案与推导](习题答案与推导.md)及[学习记录](学习记录.md)。浏览器可直接打开同目录的HTML阅读版，逐题记录草稿、折叠查看答案。阅读标记不等于掌握等级。

## 01 怎样沿流程学习

一次只完成一道题。先写结论、计算过程和理由；卡住时先找本步输入与输出，再查看公式。两三次仍不理解时，阅读该题推导，然后隔几题重新验证。可以查题干中的数字，重点是知道每一步在解决什么问题。

```text
行情和条款
  → 执行价与期限资格筛选
  → 最近合格到期月
  → IV筛选与反解
  → Greeks与Delta分档
  → Gamma定相对手数
  → Vega预算缩放总规模
  → 合并取整与增量限额
  → 累加旧目标与累计限额
  → 常规退出检查
  → 用帧开始时的实际期权仓位计算期货目标
  → 统一提交目标
  → 异步成交更新实际仓位
  → 后续对冲与退出
  → 主动清仓或到期结算
  → 汇总两条腿的盈亏
```

同一帧可以同时到期权决策和期货对冲时点。代码先计算这两类目标，最后统一提交；新期权目标不会在同一帧被当成已经成交。普通成交回报不立即触发新的Delta对冲。

章节按理解和做题的顺序安排。换月、缺值、清仓和结算属于条件分支，并不是每个交易日必须逐项走完。真实单帧顺序为：

```text
先读取实际与在途，处理停止交易生命周期及恢复所需行情
若达到显式最终清仓日时点：优先尝试清仓，结束本帧业务分支
否则：
  若到期权时点且允许处理：选约、配仓、累计风控，再检查常规退出
  若到期货对冲时点且允许处理：按本帧实际期权计算期货目标
  业务目标有变化时：统一提交完整目标
成交回报在之后更新实际持仓，后续帧重新读取事实
```

## 02 基础知识和单位

### 认购权利与买卖方向

认购买方购买一份选择权：按合同约定的执行价取得相应经济利益。买方可以放弃行权；卖方收取权利金并承担履约义务。卖出开仓建立空头，买入平仓关闭空头，并不需要把它理解成先借一份期权再归还。

“买方希望上涨”在这里指认购买方。认沽买方购买的则是按约定价卖出的权利，不能把所有期权买方都当成看涨；本策略只使用认购。

面粉采购权可以帮助理解选择权；真实MO属于欧式股指期权，行权通过现金交割完成，不是交付一篮子股票。欧式的行权时点限于到期日，不妨碍到期前在市场买卖或平仓。买方损失可以限于已付权利金；卖出认购的损失不能用已收权利金作为上限。期货对冲只针对特定敞口，不保证组合盈利。

### B01 权利与最终盈亏

一个简化采购权允许按100元购买商品，买方支付3元购买权利。到期商品分别值95元、102元、120元时，买方的行权价值与净盈亏各是多少？对应卖方的净盈亏是什么？忽略费用。这是基础概念练习，不计入后面的MO主账。

### 两种报价和一种换算

| 名称 | 含义 | 常见混淆 |
|---|---|---|
| 指数值I | 筛选执行价的基准，可由指数特征输入 | 不直接替代同月期货价计算IV |
| 期货报价F | 对应月份IM的报价，单位为指数点 | 不是期权报价 |
| 期权报价C | 购买或转让该期权的市场价格，单位为报价点 | 报价点数还要乘乘数和手数才能得到金额 |
| 执行价K | 合约条款中的固定价格 | 不随市场报价一起改变 |
| MO乘数m | 每手每报价点100元 | 不是最小下单数量 |
| IM乘数M | 每手每报价点200元 | 不是最小下单数量 |
| 净手数n | 本策略实际或目标持仓，正数多头、负数空头 | 目标、实际、在途必须分开 |

MO、IM的交易单位都是手；合约乘数用于把报价变化换成钱。例：1手MO报价上升1点，多头价值增加100元；1手IM上涨1点，多头价值增加200元。

### B02 报价变化换成现金

卖出2手MO后，报价上涨6点；同时持有1手IM多头，IM上涨3点。分别计算两条腿的盈亏，再合并。不要把MO的报价点与IM的报价点直接相减。

### 四个指标各连接什么

| 指标 | 含义 | 局部近似或用途 |
|---|---|---|
| IV或sigma | 从当前期权报价反推出的波动率参数 | 模型为解释该报价所需的波动率，不保证未来实际波动与之相同 |
| Delta | 期权报价对同月期货价格变化的敏感度 | 期权报价变化约为Delta乘期货价格变化 |
| Gamma | Delta对同月期货价格变化的敏感度 | Delta变化约为Gamma乘期货价格变化 |
| Vega | 期权报价对IV变化的敏感度 | 期权报价变化约为Vega乘IV小数变化量 |

这里的Greeks是单份多头认购的指标。空头风险方向由负手数体现。近似用于小幅变化，其他条件按题设固定；Delta变化时，不能把期末Delta当作整段行情中始终不变。

多头认购的Gamma、Vega通常为正，卖出后相应组合贡献为负。配仓时比较Gamma贡献的大小，不表示组合Gamma被抵消为零。IM主要提供一阶方向对冲，不能直接消除期权的Gamma和Vega敞口。正文敏感度计算采用源码保留口径；与严格定价导数的折现细节区别列在附录A。

IV从20%升到22%，小数变化量是0.02。代码的Vega按sigma变化1.0计量，不是直接按1个百分点计量。

### B03 波动幅度和涨跌方向

同一认购，当前商品价90元、执行价100元。到期一种情景是89或91元各一半概率，另一种情景是60或120元各一半概率。仅比较行权价值，哪种情景使权利更有价值？为什么这不等于预测商品一定上涨，也不保证买方净赚钱？

## 05 第一步 筛选资格和月份

这一阶段决定哪些合约进入后续指标计算。读取执行价和指数，统计剩余交易日，再按日期选最近的合格月。这里不使用主力、次主力的活跃度排名，也没有把跨月价格或IV期限结构作为独立选月信号。

```text
认购且处于可交易生命周期
→ K>I
→ 剩余交易日N≥5
→ 期权、同月期货、指数是本估值时点的行情
→ 在上述合格合约中取最近最后交易日
```

N不含今天、包含最后交易日，使用交易日历，不是把自然日直接相减。合约必须具备可用的同月期货条款与路由。近月、次月按到期时间区分；主力、次主力按行情系统的活跃度口径区分。

开仓要求三类行情处于同一估值时点，不能仅因它们都没超过300秒就认定同步。恢复或跨场次时，已有持仓依赖还要等待新场次行情齐备，不能用前一场次缓存冒充更新；必要行情仍缺失时会报错。

## 06 第二步 检查IV门槛并反解IV

IV是定价模型的未知波动率参数。已知当前同月期货价F、期权市场报价C、执行价K、年化期限T和利率r，寻找让模型价格与C相符的sigma。

```text
IV筛选值TV＝C−max(F−K,0)
TV≥5点：才调用当次IV反解
未得到新IV：尝试使用有效IV缓存
```

这个筛选值以同月期货为参考，不是后文的退出指标。低于5点是程序没有尝试反解，不是已证明数学上无解。满足5点也不保证反解一定可用。

当前实现优先新IV；缓存保留成功计算时点和sigma，当前配置最多使用300秒。使用缓存时，仍用当前F和当前期限重算Greeks；读取缓存不会延长原缓存时间。缺少新鲜行情会报错，不能用IV缓存绕过行情检查。详细反解和期限公式见附录。

## 07 第三步 用Delta匹配目标档

这一阶段才决定每个档位选谁。对每个目标Delta，分别寻找最近合格月份中、Greeks可用且Delta距离最小的候选。

```text
Delta距离＝abs(候选Delta−目标Delta)
```

IV是计算Greeks的输入；本步骤直接用于排序的是Delta。Gamma、Vega用于后面的数量分配。各档分别选约，同一合约可能被多个档命中，不能强制理解成四档一定选四只不同合约。距离相同时，当前实现沿用候选输入中先出现者。

## 08 第四步 Gamma决定档间相对手数

代码在理想未取整、未截限时，让各Delta档按乘数换算的Gamma贡献大小相等。这是本策略选定的分配规则。

```text
每档Gamma贡献大小＝卖出手数q × 期权乘数m × Gamma
相对手数权重w＝1/(Gamma×m)
```

同乘数下，每手Gamma贡献较大的档位，所需手数较少。这里比较贡献大小，q用卖出数量的正数；最终卖出增量再记成负数。这里的“Gamma贡献”按上式定义，不另混入其他文献中带标的价格平方的现金Gamma口径。

可以把比例看成一份计算用的配方：先确定各合约如何搭配，再由总预算决定配方复制多大。配方不是交易所的组合单位，也不保证多腿同时成交。

## 09 第五步 Vega决定整体新增规模

Vega描述IV变动对期权报价的局部影响。IV提高1个百分点意味着sigma增加0.01。

```text
每手现金Vega每单位sigma＝Vega × m
IV增加0.01时，每手空头的不利变化≈Vega × 0.01 × m

配置现金Vega预算B＝nav × vega_budget / 100
本配置B＝40000000 × 1.25 / 100＝500000
对应IV增加0.01时的理想新增不利变化＝B × 0.01
```

这个预算是当天新增组合的敏感度规模，不是保证金、支付价款或最大亏损承诺。旧仓Vega不先从当天预算中扣除；固定nav也不自动跟随盈亏复利。

先用Gamma确定一组的比例，再计算这组的Vega金额，最后用总预算缩放组数。四个真实档位共用一份预算。理想缩放关系为：

```text
已选档j的权重w_j＝1/(Gamma_j × m_j)
归一化分母D＝sum(w_j × Vega_j × m_j)
理想新增手数a_j＝B × w_j / D
```

## 10 第六步 合并取整和增量限额

理想手数不是最终可提交的手数。当前顺序是：

```text
同一合约命中多个档时先合并
→ Python round取整到手
→ 本次单合约增量截限
→ 本次总手数超限时同比缩放并int向下取整
→ 去掉零手
→ 转成负的卖出增量
```

Python的round不是所有“.5”都向上：round(2.5)＝2，round(3.5)＝4。取整和限额可能使实际Vega高于或低于理想预算；不能把原始预算当成取整后严格满足的现金上限。同比缩放后的零碎余量不会再自动补齐。

## 11 第七步 累加旧目标并检查累计限额

```text
候选新目标＝已有目标＋当日新增增量
单合约累计绝对手数≤100
全部期权累计绝对手数之和≤200
```

未选中的旧合约保留。若叠加后任一累计限额超出，当前实现拒绝整批当日新增，保留原有期权目标；这道检查不重新分配剩余容量。它与前一步对增量截限、缩放是两种处理。

这个检查发生在常规退出检查之前。不能先假设某份旧仓随后会退出，提前把容量让给新增方案。新增拒绝后，正常的旧仓退出和配置时点期货对冲仍可能继续。

工程上，这道检查只接受或退回整份拟目标，不在这里重新分配。其代价是一个合约超限时，其他仍有容量的合约也可能失去新增机会；不能仅凭这条规则断言它优于逐项接受或按剩余额度重配。

### Q10 累计限额的独立情景

## 12 第八步 检查常规退出

代码只在期权交易时点执行本条检查，先处理新增方案，再检查非零且尚可交易的期权目标。

```text
退出指标E＝C−(F−K)
E≤0：该合约期权目标设为0
E>0：本条退出规则不触发
```

等于零和小于零都触发。这个公式没有max，与IV门槛公式不同。F>K时，它表示报价扣除以同月期货为参考的未折现实值部分后的差额；F<K时，E并不是标准时间价值。它是源码采用的退出指标，不是交易盈亏，也不是已证明最优的止盈止损规则。

持仓盈亏需要开仓成本，E没有使用开仓价格，因此同样E＝0的两笔持仓，可能一笔赚、一笔亏。剩余不足5天也不自动退出旧仓；5天是新开仓门槛。

有期权在途委托时，本实现跳过该帧的期权选约及常规退出。选约只在精确配置时点触发，不在之后任意分钟补开。无新候选时仍可检查已有目标退出；两项不是同一个成功标志。

## 13 第九步 用实际期权计算同月期货目标

```text
某月实际Delta敞口X＝sum(带正负号的实际期权手数n × m × Delta)
该月IM目标H＝round(−X / M)
```

每个月份分别匹配对应的IM。表中的Delta是多头认购指标，卖出期权的n为负数，因此通常需要正的IM多头。理想手数不足半手时可能取整为零，持有期权而IM为零不一定是故障。

这里读取帧开始时的实际期权仓位。新增目标未成交的部分不提前算入；待平但尚未买回的空头仍是实际敞口。所需期货手数超过100手时，当前代码报错，不把目标静默裁到100手。

任一期货腿有在途委托时，会跳过该帧对冲，防止叠加未完成的期货调整。每个配置对冲时点正常只处理一次。缺IV导致保留旧目标时，这一次仍记为已处理。

## 14 第十步 提交目标并处理订单成交


## 17 第十三步 区分情景风险和真实盈亏

Vega、Delta是局部敏感度。它们可以做情景估算；真实成交损益则依据实际成交价、手数和成本。不能把同一笔变化既按情景估算又按现金流重复计入。

```text
小幅报价变化≈Delta×期货价格变化＋Vega×IV小数变化量
期权持仓价值变化≈带符号实际手数×m×报价变化
期货持仓价值变化＝带符号手数×M×期货价格变化
```

### 缺IV时保持哪个量

## 21 第十七步 最终清仓和到期结算

已停止交易的残仓不能再当普通可交易合约发平仓单。应等待权威现金结算及账本更新，随后清理相关目标和缓存；删除一个本地持仓字典不等于完成结算。

MO认购到期的每手结算价值为`max(S结算−K,0)×100`。S结算是交易所规定的指数交割结算价，不是直接拿IM最后一笔成交价代替。交割结算价按最后交易日标的指数最后两小时的算术平均值确定。符合行权条件的买方按规则处理，并与卖方配对；本手册的实值履约题假定已被行权配对。

## 附录A 程序中的定价与期限公式

入门先掌握输入和输出。以下保留源码数值口径，手算练习使用题设指标，不要求用它们精确还原主案例报价。

```text
N＝不含今天、包含最后交易日的剩余交易日数
选约反解IV时：T＝N/252
对冲反解IV时：T＝N/252＋当日剩余交易分钟/(240×252)
Vega折现另用：Tc＝到最后交易日的自然日差/365

d1＝[ln(F/K)＋sigma²×T/2]/[sigma×sqrt(T)]
d2＝d1−sigma×sqrt(T)
Black76认购价＝exp(−r×T)×[F×Ncdf(d1)−K×Ncdf(d2)]

源码Delta＝Ncdf(d1)
源码Gamma＝phi(d1)/[F×sigma×sqrt(T)]
源码Vega＝phi(d1)×F×sqrt(T)×exp(−r×Tc)
```

`Ncdf`是标准正态累计分布，`phi`是其密度。源码Delta、Gamma没有定价函数中的折现因子，Vega使用另一个期限Tc；它们是当前策略沿用的指标口径，不要与另一套折现定义混接。

当前r＝0.02。IV二分搜索区间为0.0001至5.0，执行64轮。函数会检查基本数值和价格边界，但没有额外的区间可达性和最终重定价误差验收，所以“返回数值”不代表所有输入都能精确重定价。

当日剩余分钟按09:30至11:30、13:00至15:00共240分钟的保留公式计算；14:00为60分钟，14:55为5分钟。这是定价期限口径，不用于决定交易所或实际合约的停止交易时点。

## 附录B 公式速查和易错点

| 任务 | 计算 |
|---|---|
| 认购到期价值 | max(S结算−K,0) |
| 买方净盈亏 | 到期价值或卖出价减去买入价，再乘手数与乘数 |
| 卖方净盈亏 | 开仓卖价减去买回价或到期结算价值，再乘手数与乘数 |
| 多头期货盈亏 | (卖出或估值价−买入价)×M×手数 |
| IV筛选值 | C−max(F−K,0) |
| 常规退出指标 | E＝C−(F−K)，E≤0触发 |
| 期权Delta敞口 | sum(带符号实际手数×m×Delta) |
| 同月IM目标 | round(−该月Delta敞口/M) |
| 无在途时调仓量 | 目标净仓位−实际净仓位 |
| 有同向在途时简化差量 | 目标−实际−已在途带符号数量 |
| 每手IV情景风险 | Vega×IV小数变化量×m |
| 理想新增现金Vega | nav×vega_budget/100 |
| Gamma档间贡献 | q×m×Gamma，相等时q成反比于m×Gamma |
| 组合盈亏 | 期权已实现与未实现＋期货已实现与未实现−费用 |

读公式时先标单位：F变化是IM报价点，Delta把它变为MO报价点；乘数再把报价点变成钱。Gamma改变的是Delta，不直接等于期权报价的变化。IV改变的是模型波动率参数，Vega才把这一步换成报价变化。

五个需要反复检查的边界：剩余恰好5天可以用于新增；E恰好0也退出；负E同样退出；round的半偶规则；目标为0不代表实际已平完。

“收取时间价值”是理解收益来源的方式，不是收益保证。动态对冲可能在上涨后增加多头、回落后减少多头，产生高买低卖成本。策略也没有“IV高于某个历史波动率才开仓”的明确比较条件，不能直接给它贴上已验证的波动率套利标签。
