# MO策略本地学习资料

直接用浏览器打开[策略流程学习手册.html](策略流程学习手册.html)。正文、公式和34道题的折叠推导均可离线阅读。草稿与练习勾选可保存在当前浏览器，并导出为JSON；它们不自动改变技能等级。

可编辑原稿：

- [策略流程学习手册.md](策略流程学习手册.md)：流程、基础知识、计算口径、同一案例题目与公式速查。
- [习题答案与推导.md](习题答案与推导.md)：逐题推导，建议作答后再看。
- [学习记录.md](学习记录.md)：当前等级、容易混淆的地方和跨聊天续接文本。
- [综合案例数据.json](综合案例数据.json)：固定题干的机器可读数据。
- [来源与校验.json](来源与校验.json)：源码指纹、案例数值与链接校验记录。

在学习目录运行以下命令可重新生成阅读版并核算材料：

```bash
python3 build_learning_reader.py
python3 verify_learning_material.py
```

阅读HTML不需要安装依赖。重新生成HTML需要`markdown-it-py`；数值校验使用Python标准库，并直接加载当前仓库的纯Python数值模块，不启动交易、回测或网络连接。
